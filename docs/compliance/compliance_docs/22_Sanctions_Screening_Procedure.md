## 1. Purpose

Define how Xego screens customers and beneficial owners against sanctions and watchlists, and how matches are handled and reported.

## 2. List Sources

OFAC SDN list, UN consolidated list, EU consolidated list, and CBN-referenced lists. Screening uses the integrated provider and is refreshed when lists update.

## 3. Screening Points

- At onboarding (before service).
- On beneficial-owner identification.
- Periodic rescreen of the full base.
- On significant name/data changes.

## 4. Match Handling

- Exact match: freeze/refuse service immediately; report to CBN/NFIU as applicable; record.
- Partial/fuzzy match: analyst review against list details (DOB, address, ID); resolve as hit or false positive.
- False positive: documented rationale; retain record.
- Confirmed hit: freeze funds/accounts, file report, notify CCO and AML/CFT Oversight Committee.

## 5. Record Keeping

All screening events (matched party, list, action taken) are logged; records retained 7 years.

## 6. References

OFAC/UN/EU guidance; CBN AML/CFT Regulation 2009.
